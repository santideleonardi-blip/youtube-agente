Privacy Policy

Last updated: November 14, 2026

youtube-agente is a personal automation tool operated by one owner for their own YouTube channels (WhatWouldHappenIf? and StickRider). It is used only with the owner's own Google account.

Data accessed

With the owner's explicit authorization (OAuth), the tool uses YouTube API Services to: upload videos to the owner's channel, set titles, descriptions and thumbnails, read public video statistics, and read the channel's own YouTube Analytics reports (such as audience retention).

How data is used and stored

This data is used only to produce and improve videos for the owner's channel. Aggregated statistics about the channel's own videos are stored in the tool's private configuration. No data is sold, shared with third parties, or used for advertising. No data from other users is collected.

Google API Services

youtube-agente uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy. Access can be revoked at any time at https://myaccount.google.com/permissions.
